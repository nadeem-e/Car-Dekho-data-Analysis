# Car Dekho Used-Car Data Analysis

## Project Overview
This project focuses on analyzing a used-car dataset to understand market trends and identify the factors that influence car selling prices. The project covers data cleaning, feature engineering, exploratory data analysis (EDA), and interactive dashboard development.

## Tools & Technologies
- **MySQL & MySQL Workbench** – Data cleaning and exploratory data analysis
- **Microsoft Power BI** – Interactive dashboard development and data visualization

## Project Workflow
- **Data Cleaning:** Checked data quality, identified missing values, and handled duplicate records.
- **Feature Engineering:** Created additional features such as car age and categories for engine capacity, maximum power, torque, and mileage.
- **Exploratory Data Analysis:** Performed univariate, bivariate, and multivariate analysis to explore patterns and relationships in the dataset.
- **Dashboard Development:** Built an interactive Power BI dashboard to analyze selling prices, fuel types, transmission, ownership, car age, and vehicle specifications.

## Key Objectives
- Understand the distribution of used cars across different fuel types, ownership types, and transmission types.
- Explore the relationship between car age, engine capacity, maximum power, and selling price.
- Identify patterns in used-car pricing.
- Present insights through clear and interactive visualizations.

## Learning Outcomes
This project provided hands-on experience with SQL-based data cleaning, feature engineering, exploratory data analysis, and Power BI dashboard development. It also helped strengthen my analytical thinking and problem-solving skills.
